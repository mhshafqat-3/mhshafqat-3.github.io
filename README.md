# void — Developer Portfolio

A lightweight, responsive static portfolio using HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — homepage, about, skills, tools, and contact.
- `projects.html` — separate projects page with editable project cards.
- `style.css` — shared styling for both pages.
- `script.js` — mobile navigation and small interactive details.

## Customize
- Edit `index.html` to change your bio, skills, email, and profile links.
- Edit `projects.html` to update project names, descriptions, technology tags, and repository/demo URLs.
- Replace `your.email@example.com` and `mhshafqat-3` with your actual contact details.
- Adjust colors and layout in `style.css`.

## Preview locally
From this directory, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment completes, GitHub will show the public website URL in Pages settings.

No build step or package installation is required.
